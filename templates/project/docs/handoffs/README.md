# docs/handoffs/

Task handoff notes: work in progress written down for another agent, another session, or
your future self. The template and the rules live in the `handoff-note` skill; `/handoff
<slug>` writes one.

## Naming

```
<YYYY-MM-DD>_<slug>.md
# e.g. 2026-10-20_ch7-figure-rework.md
```

## What goes in

A TL;DR, a *How to resume* matrix keyed on observable states, a numbered roadmap with one
owner per step and **user checkpoints** in bold, locked decisions, copy-paste agent
invocations, failure modes with options, files of interest, a FAQ.

## What stays out

Results. Numbers live in evidence notes; a handoff points at them.

## Lifecycle

`Status: open | in-progress | blocked | done`. Update in place; log changes at the bottom;
never delete.
